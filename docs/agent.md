## Database rules (set by the project owner)
- Never create, edit, rename or delete files in supabase/migrations or supabase/tests unless the owner pastes the exact SQL and the exact file name.
- Never write your own migration. Never run SQL. Never open the Supabase dashboard in a browser.
- Only change the files the owner lists. If a listed change seems to need something that was not listed (a database function, a migration), STOP and report it instead of inventing it.
- Before finishing, run npm run lint and npm run build and report the results honestly.
